# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化、撤销重做与字号偏好恢复。

## 多标签接力值守

两位同传各开一个标签页值守同一条后台队列时，所有操作按条目合并，不会互相覆盖：

- **按条目合并**：确认、补译、术语提醒都按条目合并；两人同时确认不同条目互不影响，同一条目两人先后处理则保留两版补译，并标记谁先确认（卡片显示“先确认 · 译员 A”，舞台字幕标注确认人）。
- **冲突提示**：同一条目两人处理不一致时，晚到一方的页面出现红色冲突条，列出双方版本与时间，可选择“采用先到版本”或“保留我的版本”，选择同步到双方。
- **舞台不回退**：已确认上舞台的字幕后，任何合并或撤销都不会退回未确认状态；会导致回退的选项在界面上禁用。
- **撤销只管本页**：`Ctrl+Z` 只撤销本标签页的编辑，撤销后重新合并，不动对方的确认与提醒。
- **失败重试**：合并写入失败时右上角出现红色提示条，可“立即重试”，随后自动重试；失败期间本机操作不丢失、不覆盖对方内容。
- **工位身份**：每个标签页首次打开时领取一个工位身份（译员 A/B/C/D），保存在本标签页 sessionStorage；顶栏显示“本页 · 译员 X”。

合并采用三路合并（上次同步快照 / 本页状态 / 队列最新状态）：配置实体按更新时间后写胜出，字幕状态与补译按上述规则合并，提醒按条目去重、确认状态取并集。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，所有管理员配置、现场队列和暂存内容通过 `localStorage` 中的共享队列（`conference-cue-desk-v2`）在多个标签页间同步；旧版本数据（`conference-cue-desk-v1`）首次打开时自动迁移。清理站点数据会移除本地记录。
