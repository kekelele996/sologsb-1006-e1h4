# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- **双岗接力**：两个标签页各代表一名值守人，确认、补译、术语提醒按条目三方合并，后保存不再整体覆盖。
- 同一条两人先后处理时两版并存，标出谁先确认；晚到一方看到冲突提示后在冲突面板挑选采用版本。
- 舞台字幕只追加、不回退；撤销/重做按标签页隔离，只回退本页自己的动作；合并失败可一键重试。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认（多人发送并列署名，已看到名单各自独立）。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后按条目合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化（共享队列 v2 + 本页值守人偏好）、撤销重做与字号偏好恢复。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，数据都在当前浏览器：

- 共享队列保存在 localStorage（`conference-cue-desk-v2`），同一浏览器的多个标签页通过
  `storage` 事件做按条目三方合并；旧版 v1 数据首次打开时自动迁移。
- 值守人名称、字号、当前选中条目等仅属于本标签页，保存在 sessionStorage
  （`conference-cue-desk-operator-v1`），不参与合并。
- 清理站点数据会移除本地记录。

## 接力值守的合并语义

- **确认 / 补译**：按值守人追加，同一条多人处理则多版并存，舞台与队列标出“先确认/先补”和“接力”。
- **术语提醒**：同术语同条目合并为一条，发送人并列；“已看到”按人独立标记，名单只增不减。
- **舞台字幕**：`stageLines` 只追加，撤销确认只摘掉本人署名，已上舞台的内容永不回退。
- **正文编辑冲突**：两人基于同一版本改成不同值时保留两版，默认留本页版本，晚到方在右侧冲突面板挑选。
- **撤销**：每个标签页独立操作日志，撤销只作用于本页动作；删除通过墓碑（tombstone）传播，避免对端旧快照复活。
- **失败重试**：写入或合并失败时草稿保留在本页，顶部红条提供“重试合并”。
